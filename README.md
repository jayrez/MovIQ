# MovIQ

Guess a movie title from a badly explained plot in six attempts. Open `index.html` in a browser or serve the repository as a static site. There is no install or build step.

Type the full title or skip the fixed hint letters with the on-screen or physical keyboard. Backspace erases only letters you entered. The board supplies spaces and punctuation and reveals a few letters in longer words. Green indicates an exact match. Yellow indicates an unmatched copy of the letter elsewhere in the same word. Previous guesses remain visible while you play.

Add movies to `movieList` in `data.js` using the existing prompt and answer fields. The current catalog uses English letters, spaces and punctuation. Movies shuffle without repeats until the catalog is exhausted.
